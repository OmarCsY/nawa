## ما نُفذ واختُبر
- المحرك المشترك للويب وWAHA، بجلسات أسر ديمو مستقلة وموافقة وعدد ومدينة وإيقاف وعودة.
- المسودات والتعديل والتأكيد الذري، ملكية الأسرة، الإصدارات ومنع تكرار الطلبات والحفظ وتقديم الوقت والتعلم.
- المناسبات والأسئلة القصيرة، forecast والنشرة، خطط plan_library وBeta sampling، القبول والتذكير والتطبيق والقياس اللاحق وfn_record_outcome.
- رحلة HTTP إنتاج كاملة على قاعدة عمر حتى النتيجة، وعبور أسبوع مع التذكير والمتابعة والنشرة الأسبوعية والملخص الشهري. أُصلح تحويل JSON في النشرة الأسبوعية بعد أن كشفه هذا الاختبار.
- تفريغ فعلي عبر Gemini للصيغ WebM/Opus وOgg/Opus وMP4/M4A AAC-LC (حاوية عادية ومجزأة). استخراج AAC يتم في الذاكرة، بلا ملفات تحويل إضافية.
- رفض ملف مزيف ومبتور، صوت 91 ثانية وملف أكبر من10 MiB قبل التحليل. الصمت أعاد خطأ تفريغ واضحًا وبطاقة null، دون اختلاق قياس.
- تنظيف binary_data بعد النجاح والفشل، وTTL ساعة واحدة للانقطاعات مع فحص كل5 دقائق. الإضافة محصورة في تدفقي محرك نَوء ووصلة واتساب. تحقق نظام الملفات بعد اختباري MP4 الناجحين واختبارات الفشل وجد صفر ملفات صوت باقية. اختبار TTL على الخادم حذف ملفًا اصطناعيًا قديمًا وأبقى الحديث ثم حذفه عند إكمال التنفيذ.
- CORS لنطاق https://nawa-litadoom.vercel.app. القياس المؤكد ظهر في v_live ووصل INSERT إلى اشتراك Supabase Realtime بمفتاح عام.
- اختبار المستخدم الحقيقي بعد التحويل: تسجيل واتساب وصوتية500جرام خبز وتأكيدها؛ القياس نهائي في measurements وأصنافه وlive_feed، و7 ردود مؤكدة من WAHA.
- اختبارات SQL للذرية والعزل وانتهاء المسودات والإيقاف والنتيجة ومنع تكرار التعلم، مع rollback لبيانات SQL. بيانات اختبارات HTTP أسر ديمو اصطناعية مستقلة محفوظة وموسومة، وليست نقل بيانات القاعدة القديمة.
- ملفات العقد والاختبارات وتصدير التدفقات منقحة من الأسرار. لا تغييرات على ملفات واجهة عمر.

## حدود التسليم والخطوة التالية
المرحلة الثانية الخاصة بالمحرك مكتملة ومختبرة ضمن الأدلة أعلاه. ربط engineAdapter.ts وصفحة /docs وواجهة النشرة واللوحة المنشورة هو عمل المرحلة الثالثة لدى عمر/Claude. لم يُختبر جهاز آيفون فعلي؛ الاختبار كان ملفات AAC داخل MP4/M4A. اختبار WhatsApp بعد التحويل أثبت التسجيل والصوت والتأكيد؛ رحلة المناسبة والخطة والنتيجة الكاملة اختُبرت عبر HTTP والدوال المشتركة، ولم تُنتظر أيام حقيقية على واتساب. روابط أدوات لتدوم غير المزودة تبقى null كما هو موثق.

demo-review.html واللقطات والفيديو عرض منقح لردود HTTP الفعلية المحفوظة في full-story-results.json؛ ليس تسجيل واجهة واتساب. لا يتضمن أرقامًا أو مفاتيح أو جلسات. أي فيديو واتساب أصلي للشرائح يحتاج تسجيل محادثة المستخدم الفعلية.

الرابط على خادم عام، ولا يعتمد على بقاء جهاز المستخدم مفتوحًا. تحقق health نجح بعد إعادة تشغيل الخدمة؛ لا يمثل هذا ضمان توفر مستقبليًا، ولذلك يلزم فحصه قبل العرض.
